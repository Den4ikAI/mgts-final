## 3. Сквозной пример

Одно фото кабельного колодца с открытым или повреждённым люком из датасета организаторов.

| Поле | Ключ | Как выбрать |
|---|---|---|
| Файл | `example.file` | фото из датасета, в разметке организаторов дефект люка |
| ID объекта | `example.object_id` | из колонки ID разметки; если её нет, `IMG-<имя файла>` |
| Координаты | `example.lat`, `example.lon` | из разметки; если нет, на слайдах только ID |
| Вид дефекта | `example.defect_label` | русская метка класса из `/api/taxonomy` после правки `taxonomy.json` |
| Опасность | `example.severity_label` | ожидаем «Угроза жизни» |
| Уверенность | `example.confidence` | из `predictions.jsonl` прогона `final` |
| Маршрут | `example.route` | ожидаем `critical` (тревога в обход очереди) |
| Объяснение модели | `example.rationale` | строка `rationale` детекции |
| Проверено руками | `example.verified_by`, `example.verified_at` | кто посмотрел фото и сверил с разметкой |

Правила выбора:
1. Разметка и ответ модели совпадают в прогоне `final` и в повторном прогоне из кэша.
2. Кадр типичный для датасета, люк читается с проектора без увеличения.
3. На кадре нет лиц и читаемых номеров машин. Если есть, берём другой кадр [ЧЕСТНО: размытия в продукте нет].
4. Пример называется везде одинаково: «открытый люк {{example.object_id}}» (или метка класса организаторов, если она другая).

Где появляется: 02 pain (5:00), 02/03 trace, 03/04 product, 05 mechanic (5:00), финал 5:00 (главная цифра). На слайде limits пример не появляется: там кадры с маршрутом `not_observed`.

Если в датасете нет класса «открытый люк», берём самый опасный класс колодца из разметки организаторов и
меняем подпись примера во всех файлах одной заменой.

## 7. Открытые вопросы

- Слот экспресс-защиты в секундах и есть ли отдельное время на вопросы.
- Есть ли в датасете координаты и ID объектов (`dataset.has_coordinates`, `dataset.has_object_ids`). Без координат карты нет, выдуманные точки не показываем.
- Классы дефектов организаторов и есть ли среди них открытый люк.
- Есть ли повторные снимки одного объекта. Без них «объект во времени» звучит как план, не как результат.
- Отдельный тестовый набор с разметкой или один датасет. От этого зависит, честен ли выбранный порог (см. qa.md, вопрос 6).
- Колонка координат в реестре `/objects`: сейчас её нет [НУЖНО ПРОВЕРИТЬ, нужна для R5, если координаты придут].
- Адрес стенда и репозитория для QR, открывается ли репозиторий без входа.
