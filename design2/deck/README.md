# Дека защиты «Попутно» · v4

HTML-дека 1920×1080. Основной трек на 5:00 (12 слайдов), экспресс на 3:00 (7 слайдов). Светлая тема бренда; блоки и анимации взяты из двух референсов команды (`screen_for_debug/preza/`: LOTIVE и «Узел») и переложены на токены «Попутно».
Речь: `speech.md`, вопросы жюри: `qa.md`, демо: `demo-runbook.md`, текст слайдов: `slides.md`.

## Сборка

```bash
cd design2/deck
python3 tools/build-data.py        # цифры прогона ml/runs/dss-final2 → numbers.json, фото с рамками → assets/photos/
python3 tools/make-qr.py           # QR «Решение» и «Код» → assets/qr/*.svg (ссылки из numbers.json → urls.*)
python3 tools/build-deck.py        # src/slides.html + numbers.json → index.html
python3 tools/build-standalone.py  # одна HTML-ка без внешних файлов → design2/deck-poputno.html
# PDF: из design2 запустить python3 -m http.server 8080, затем
NODE_PATH=<node_modules с playwright> node tools/export-pdf.cjs   # deck.pdf, deck-3.pdf
```

**Править текст слайдов только в `src/slides.html`**, `index.html` перезаписывается сборкой.
`{{key}}` в шаблоне берёт значение из `numbers.json`; если оно `null`, на слайде видна жёлтая плашка «[ДАННЫЕ] key».

| Файл | Что это |
|---|---|
| `src/slides.html` | Исходник всех слайдов |

## Как показывать

- `index.html` (по умолчанию трек 5), `index.html?track=3`, `?track=all`.
- `?static`: последний кадр без движения (для проверки и скриншотов), `?print`: все слайды подряд.
- Клавиши: → пробел PgDn Enter вперёд, ← PgUp назад, Home/End, R повторить анимацию слайда, F полный экран. Клик в левой трети экрана назад.
- На слайде «Сайт» стрелка вправо сначала листает экраны (сводка → проверить фото → очередь → реестр → качество), потом идёт дальше.
