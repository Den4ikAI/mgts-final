# Попутно · сайт-продукт

Статическое SPA без сборки: `index.html`, `css/app.css`, `js/app.js`, `js/router.js`, `js/views/*.js`, `js/ui/*.js`.
Данные идут через слой `js/data/` (см. `data/README.md`). Цвета, шрифты, иконки и знак берутся из `../brand/`.

## Запуск

Сайту нужна папка `brand/` рядом, поэтому сервер поднимаем из `design2/`, не из `site/`:

```bash
cd design2
python3 -m http.server 8080
# открыть http://localhost:8080/site/
```

Работает офлайн, кроме вызова модели: шрифты, иконки и SheetJS для XLSX (`js/vendor/xlsx.full.min.js`, 0.18.5) лежат локально.
Карты нет: в датасете организаторов нет координат, и сайт их не выдумывает. Демо-набор удалён.

Полезные параметры адреса: `?source=file|api`, `?api=http://host:8080`, `?role=dispatcher|manager|technician|admin`.

## Данные

- **Датасет организаторов** лежит в `data/dataset/`: 62 фото (повёрнуты по EXIF, ≤1600 px), ответы модели из прогона
  `ml/runs/dss-final2`, рамки Jev из `data/crops/boxes.jsonl`, разметка из `labels.csv` и `report.json`.
  Пересборка: `ml/.venv/bin/python design2/site/data/dataset/build.py` из корня репо.
- **Загрузки** хранятся в IndexedDB браузера поверх датасета. «Скрыть датасет» на странице «Загрузить данные» убирает 62 фото
  из очереди и реестра, «Удалить загрузки» стирает своё.
- **Таксономия** `data/taxonomy.json` = копия `ml/taxonomy.json` + блок `ui` и рекомендации. Вопросы модели берутся из неё,
  поэтому при правке `ml/taxonomy.json` надо скопировать изменения и сюда.

## Живая модель

`js/data/inference.js` повторяет `ml/decision.py` и `ml/crop.py` в браузере: `google/gemini-decision-1` (фото ≤2048 px,
те же вопросы, то же правило маршрута) и `typesafe/jev-1.14` (рамка вокруг шкафа), параллельно. OpenRouter разрешает CORS.
Ключ вводится на странице «Проверить фото» или «Загрузить данные» и хранится только в localStorage этого браузера.

- «Проверить фото»: одно или несколько фото → ответ с рамкой, кадр сразу в очереди.
- «Загрузить данные»: папка тестового набора → по 6 фото параллельно, прогресс, итог (в очередь / норма / не наблюдается / цена).
  Если вместе с фото положить таблицу разметки (CSV/XLSX), строки склеятся по имени файла и посчитается качество
  (при скрытом датасете; иначе на странице «Качество» остаётся отчёт по датасету).
  Если среди файлов есть `predictions.jsonl`, модель не вызывается: фото просто прикрепляются к готовым ответам.

## Маршрут жюри

| # | Действие | Что видно |
|---|---|---|
| 1 | Открыть сайт, роль «Диспетчер» | «Очередь проверки»: реальные фото датасета с рамкой, аварийные первыми |
| 2 | Карточка кадра | ответ модели, вероятности, разметка организаторов и совпадение, рекомендация |
| 3 | **Y** / **N** + причина / **R** | решение диспетчера, статус объекта меняется |
| 4 | «Проверить фото» → новое фото | модель отвечает за 2–4 с, кадр появляется в очереди |
| 5 | «Загрузить данные» → папка тестового набора | вся пачка проверяется и попадает в очередь |
| 6 | «Качество модели» | точность 91,8% на 61 фото, матрица ошибок, где модель ошиблась, перебор порога |
| 7 | «Объекты» → «Выгрузить перечень» | CSV: ID, тип, статус, дефект, разметка, рекомендация |

## Горячие клавиши

`/` поиск объекта · `?` подсказка · `T` тема · `G` + буква: S сводка, Q очередь, O объекты, N наряды, K качество, I загрузка, C проверка фото, A о системе.
В очереди: `Y` подтвердить, `N` ложное (+ `1…6` причина, `Esc` назад), `R` нужен кадр, `J`/`K` или стрелки, `Enter` открыть объект. Русская раскладка тоже работает.

## Правила кода

- В `css/app.css` нет HEX: только `var(--…)` из `brand/tokens.css` (`grep -nE '#[0-9a-fA-F]{3,8}\b' css/app.css` пуст).
- Все числа на экранах берутся из слоя данных (`selectStats`, `selectQueue`, `dataset.quality`…), подписи классов из таксономии.
- Движение: до 300 мс, ease-out, только transform и opacity; действия с клавиатуры не анимируются; `prefers-reduced-motion` учтён.
- Экран: `export default { title, render(root, ctx) → { update?, destroy?, keydown? } }`. `update()` вызывается при живых событиях источника.

## Известные ограничения

- Наряды: в API нет эндпоинтов, наряды работают в памяти браузера.
- Фото датасета публикуются вместе с сайтом (папка `data/dataset/photos`).
- `js/data/selftest.html` писался под удалённый демо-набор и часть проверок не пройдёт.
