## 1. Продукт и имя

- **Имя продукта: «Попутно»** (лат. `poputno` для путей, файлов, доменов). Пишется с заглавной, в кавычках
  в тексте только при первом упоминании. Логотип — строчными: `попутно`.
- **Что это:** система мониторинга кабельных колодцев и опор двойного назначения МГТС по кадрам камер
  служебных машин. Машины и так проезжают 20–100 км за выезд ([ИСТ] слайд 4 профильного вебинара) —
  камера смотрит по пути, без отдельных выездов.
- **Обещание (одна строка):** «Машины уже едут. Инфраструктуру проверяем попутно.»
- **Короткий дескриптор:** «Мониторинг инфраструктуры МГТС с камер служебных машин».
- **Механика продукта (из 01):** фото → модель находит объект и дефект с уверенностью → правило маршрута:
  уверенная норма закрывается сама, сомнительное — диспетчеру, критичное — тревога в обход очереди →
  наряд бригаде → следующий проезд подтверждает ремонт. Единица анализа — объект во времени, не кадр.
  Честный статус «не наблюдается» отдельно от «нормы».
- **Команда:** название команды неизвестно. Везде, где нужно имя команды, ставь видимый плейсхолдер
  `Команда [НАЗВАНИЕ]` и маркер `[TODO: имя команды]` в исходнике.
- Кейс: кейс-чемпионат МГТС «Код города», направление «Сетевая инфраструктура и сервис», финал 26.11.2026, МТУСИ.

## 2. Идея айдентики

**Рамка обнаружения.** Четыре уголка вокруг объекта — то, как камера «замечает» колодец или опору.
Через рамку проходит линия маршрута: машина едет мимо и попутно отмечает объект.

- **Знак:** квадратная сетка 64. Четыре угловые скобки (рамка детекции, толщина штриха 6, длина плеча 16,
  скругление внешнего угла 2), внутри — круг-точка (люк сверху / объект, Ø 16, центр 32,32), через центр
  горизонтально проходит линия маршрута (толщина 6), которая выходит за рамку слева и справа и
  обрывается срезом. Цвет: скобки — `signal`, точка — `scan` (циан), линия маршрута — `signal`.
  Знак должен читаться в 16 px (там линия маршрута может исчезнуть — вариант favicon).
  Это стартовое ТЗ — дизайнер может улучшить геометрию, но идея «уголки + объект + маршрут» сохраняется.
- **Анимация знака:** линия маршрута прорисовывается слева направо (машина едет) → уголки «защёлкиваются»
  к объекту из чуть большего масштаба → точка загорается циановым. ~900 мс, ease-out. Та же анимация —
  загрузчик в продукте.
- **Логотип:** знак + слово `попутно` (Unbounded 600, строчные, трекинг −2%). Варианты: основной (на светлом),
  на тёмном navy, монохром светлый, монохром тёмный, на `signal`. Охранное поле = ширина плеча уголка (16/64 высоты знака). Мин. размер знака 16 px, логотипа 96 px по ширине.
- **Фирменный приём на всех носителях:** уголки рамки (corner brackets) — рамки фото-доказательств,
  фокус карточек, акцентные плашки в слайдах, бейдж «найдено моделью». Плюс тонкая «линия маршрута»
  как разделитель / таймлайн / прогресс.
- **Кивок организаторам без копирования:** тёмная navy-основа и синий рядом с МГТС `#008AE0`;
  их оранжевый куб превращён в смысл: тёплый оранжевый у нас означает ТОЛЬКО «дефект, нужен ремонт».
  Кубы, градиентные заголовки, шрифты MTS — не копируем. Логотипы МГТС/чемпионата — только в строке
  «Кейс МГТС · Код города» на обложке деки, по правилам совместного размещения (раздел в брендбуке).

## 3. Цвет (два слоя: палитра → смысловые токены)

Принцип: **бренд холодный, тёплые цвета — только состояние объекта.** Это правило брендбука.

Палитра (шкалы 50…950 строит дизайнер, ниже — опорные точки):
- `navy` (основа): 950 `#030E1C`, 900 `#061A2E`, 800 `#0A2540`, 700 `#123354` — опора на фон организаторов `#051B29`/`#030E24`.
- `signal` (бренд-синий, рядом с МГТС `#008AE0`): 500 `#0A84E6`; для текста/кнопок на светлом — 600 `#0068C2` (≥4.5:1 на белом).
- `scan` (циан «камера заметила», нод к `#28D8ED`/`#00C5F7`): 400 `#2ADCF0`. Только акценты на тёмном, рамки детекции, фокус, «модель видит». Не для текста на светлом.
- нейтрали холодные `slate` 0…950 (от `#F5F8FB` до `#0B1520`).
- Статусы объекта (каждый ещё имеет форму/иконку — цвет не единственный носитель):
  - `ok` «Норма» — зелёный `#1FA971` (галочка);
  - `suspected` «Проверить» — жёлтый `#E8B520` (вопрос / треугольник);
  - `defect` «Дефект» — оранжевый `#EC7A1C` (от куба организаторов; гаечный ключ / ромб);
  - `critical` «Критично» — красный `#E5383B` (молния / восклицание, может пульсировать один раз);
  - `not_observed` «Не наблюдается» — серый + пунктирный контур `#8A97A8` (перечёркнутый глаз).
- Опасность (severity: low/medium/high/critical) — шкала по тем же тёплым цветам, тот же порядок.

Темы: **тёмная — основная** (диспетчерская, проектор, дека), **светлая** — для бригады на телефоне днём и
печати. Тёмная тема не инвертирует палитру, а переназначает смысловые токены (как Factmap).
Контраст текста ≥ 4.5:1 в обеих темах — проверить и показать в брендбуке.

## 4. Типографика

- **Unbounded** (variable 400–800) — дисплейный: обложки, заголовки разделов, крупные цифры KPI, логотип.
  Не для текста < 20 px и не для абзацев. Широкий гротеск — кивок к MTS Wide организаторов.
- **Golos Text** (variable 400–900) — интерфейс и текст.
- **JetBrains Mono** (400–700) — ID объектов (`MH-0142`, `POLE-0037`), координаты, уверенность (`0.93`),
  время, имена токенов. Цифры везде табличные (`font-variant-numeric: tabular-nums`).
- Шрифты лежат локально: `design2/brand/fonts/` + `fonts.css` (@font-face с относительными путями). Работать офлайн.

## 5. Голос

«Внимательный обходчик»: коротко, конкретно, с местом и временем. Неизвестное называем неизвестным
(«Не наблюдается: снег», а не «Норма»). Система подсказывает — решает человек.
Пишем: «Открытый люк, ул. Авиамоторная, 8 · уверенность 0.95 · 26.11 10:42». Не пишем: «Обнаружена
потенциальная угроза!!!», «ИИ точно определил». Без тире-конструкций в UI и на слайдах; правила humanizer из 04.
Запрещённые слова: является, позволяет, уникальный, инновационный, мощный, высокая точность, масштабируется,
«не просто X, а Y».

## 6. Файлы и структура (всё в /media/denis/work4/mgts_hack/design2)

```
brand/
  fonts/            шрифты + fonts.css (готово)
  tokens.css        ЕДИНСТВЕННЫЙ источник токенов (палитра + семантика light/dark + type + space + radius + motion)
  components.css    базовые компоненты на токенах (кнопки, пилюли статусов, рамка детекции, карточки, поля, таблица, тосты)
  logo/             mark.svg, logo.svg, logo-dark.svg, logo-mono-*.svg, favicon.svg, mark-anim.svg (или CSS)
  index.html        брендбук (самодостаточная страница, ссылается на tokens.css/components.css/fonts)
deck/               дека защиты (берёт ../brand/tokens.css, без своих цветовых литералов)
site/               сайт-продукт (берёт ../brand/tokens.css и components.css)
notes/              заметки и этот бриф
```

Правило синхронизации (deck-design-sync): цвета/шрифты/радиусы в деке и на сайте — только через
`var(--…)` из `brand/tokens.css`. grep по HEX в CSS деки и сайта должен быть пустым (кроме data-URI).
