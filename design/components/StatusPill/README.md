# StatusPill

Пилюля статуса объекта: точка плюс подпись. Варианты: `mg-pill--ok`, `--suspected`, `--defect`, `--unseen` (полая точка) и `--critical` (сплошная заливка, только для угрозы жизни).

Подпись пишет потребитель: «Норма», «Проверить», «Дефект», «Не наблюдается», «Открытый люк». Цвет без подписи не используется.
