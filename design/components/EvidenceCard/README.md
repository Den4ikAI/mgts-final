# EvidenceCard

Карточка-доказательство: по ней диспетчер решает, верить ли системе, не выезжая на место.

Состав: заголовок с ID и адресом, пилюля статуса, два кадра рядом («Было» прошлый проезд, «Сейчас» с bbox в `mg-bbox`), одна строка обоснования модели, метаданные (проезды, машина, время) и кнопки решения. Для угрозы жизни добавьте `mg-evidence--critical`. Кадры и bbox (в процентах кадра) передаёт потребитель.
