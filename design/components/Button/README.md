# Button

Кнопка действия. `mg-btn` по умолчанию вторичная, `mg-btn--primary` одна на экран.

В очереди разбора решения идут кнопками `mg-btn--confirm` («Подтвердить», Y), `mg-btn--reject` («Ложное», N) и обычной («Нужен кадр», R), подсказка клавиши в `mg-kbd`. В мобильном наряде добавляйте `mg-btn--large`.
