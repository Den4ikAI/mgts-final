# МГТС Инфраструктура

Интерфейс мониторинга кабельных колодцев и опор двойного назначения для Департамента сетевого сервиса МГТС. Им пользуются диспетчер (разбирает очередь), бригада в поле (открывает наряд с телефона) и руководитель (смотрит сводку). Стиль взят со слайдов МГТС: глубокий тёмно-синий, фирменный синий, неоновый циан.

## Как говорим

- По-русски, языком эксплуатации: «колодец ККС-0412», «наряд», «проезд», «бригада». Не «объект #4f2a», не «инстанс».
- Уверенность модели словами, а не процентами: **точно / вероятно / проверить**. Проценты только в детальной панели.
- Каждое срабатывание приходит с доказательством: кадр, bbox, одна строка обоснования («Крышка смещена, виден проём»).
- Честное «не знаю». Если объект под снегом или перекрыт машиной, пишем «Не наблюдается с 12.11», а не «Норма».
- Кнопки называют действие: «Подтвердить», «Ложное», «Нужен кадр». Без «ОК» и «Отправить».

## Статусы объекта

Четыре статуса, у каждого свой цвет и форма. Статус всегда показывается пилюлей или пином, никогда только цветом текста.

| Статус | Токен | Когда |
|---|---|---|
| Норма | `status-ok` | объект виден, дефекта нет |
| Проверить | `status-suspected` | модель нашла дефект, диспетчер ещё не разобрал |
| Дефект | `status-defect` | подтверждён диспетчером |
| Не наблюдается | `status-unseen` | не видно (снег, перекрытие) или давно не проезжали. Пин полый |
| Критично | `critical-fill` | угроза жизни (открытый люк на проезжей части). Сплошная заливка и свечение, обходит очередь |

## Визуальные основы

- **Темы.** Тёмная основная (диспетчерская, большой экран). Светлая для дня и поля: на улице тёмный экран не читается.
- **Цвет.** `accent` (циан) только для навигации, фокуса и рамки bbox. Статусы его не используют. `brand` для одной главной кнопки на экране.
- **Шрифты.** Unbounded (широкий, как заголовки слайдов МГТС) только для `display` и `title`. Golos Text для интерфейса. JetBrains Mono для ID, координат и цифр сводки (`data`, `kpi`), чтобы колонки выравнивались.
- **Форма.** Карточки скруглены (`radius-lg`), как плашки на слайдах. Пилюли и пины круглые (`radius-pill`).
- **Свечение.** `glow-accent` для фокуса и выбранного элемента, `glow-critical` только для критичного. Других теней нет.
- **Поле.** Кнопки в мобильном наряде `mg-btn--large` (56px): нажимаются в перчатках.

## Компоненты

Система на CSS: подключите `tokens.css` и `components/bundle.css`, классы с префиксом `mg-`. Angular-приложение (`web/`) использует их напрямую.

- **StatusPill**: статус объекта.
- **Button**: действия и решения в очереди, с подсказкой горячей клавиши.
- **EvidenceCard**: карточка-доказательство «было / стало» для разбора.
- **QueueRow**: строка очереди разбора.
- **MapPin**: пин на карте по статусу.
- **KpiTile**: плитка сводки руководителя.

## Иконки и логотип

Логотипа МГТС в системе нет: на хакатоне используем текстовую марку «МГТС» шрифтом Unbounded. Иконки берём из Lucide (обводка 1.5px, цвет `ink-muted`) и не придумываем свои.
